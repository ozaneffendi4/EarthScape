eProject Process Overview

Dear Student,

Welcome to eProjects

It gives us immense pleasure to address you about eProjects. This is a new way of learning, which would value add the existing course material that has been provided to you.

You are requested to read the MS-WORD/PDF document carefully, it contains the eproject specification to be done by you.


Status Report Submission

During the project tenure, students are required to submit two status reports at an equal interval (viz. every 7th / 10th day or accordingly).

Each status report should include:
• Overall progress of the project development.
• Tasks completed and current status.
• Challenges, if any.
• Supporting files such as developed source code, database scripts, screenshots, or other relevant documents for progress verification.
• All files should be put together in a folder, ZIP the folder and submit it to us through Query/Status section.


Final Project Submission

On completion of the project, students must prepare a single compressed (ZIP) folder containing all project deliverables, including:
• Complete source code
• Project documentation including login credentials for the project/database etc.
• Database backup
• Any other relevant project files

The ZIP folder should be uploaded as the final project submission.

Note: The ZIP folder name should clearly indicate the Batch, Group, and Project Title to facilitate easy identification during evaluation.

IMP: ONLY ONE SUBMISSION IS ALLOWED PER GROUP. HENCE, ONCE SUBMITTED, NO ADDITIONAL OR CHANGE OF FILE WOULD BE ALLOWED. THEREFORE, CHECK CAREFULLY FOR ALL RELEVANT FILES TO BE INCLUDED IN SUBMISSION.
