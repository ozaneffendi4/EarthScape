# Website demonstration
The completed browser demonstration is included as Website_Demonstration.mp4. It shows authentication, overview, station filtering, models, data explorer, the real Hadoop job result, ingestion, live threshold alerts, support resolution, backup creation, mobile layout and viewer restrictions.

To make another recording, start the application and run tools/record_website.cjs with Playwright installed, or record the screen manually. A fresh recording is optional; the provided video is part of the submission package.
