# EarthScape
### Climate Analytics & Environmental Data Intelligence

EarthScape is a climate analytics platform built with **Python and JavaScript**. It brings data ingestion, interactive visualization, temperature forecasting, anomaly detection, and alert management into a unified application.

The platform helps users explore climate observations, monitor weather stations, identify unusual patterns, and manage data processing workflows through a central dashboard.

---

## Key Features

| Feature | Description |
|:--|:--|
| **Interactive Dashboards** | Explore climate indicators and trends through visual summaries. |
| **Station Monitoring** | View station-level observations and compare environmental conditions. |
| **Data Explorer** | Examine climate records in a dedicated exploration interface. |
| **CSV & JSON Ingestion** | Import climate datasets for analysis and processing. |
| **Temperature Forecasting** | Generate temperature forecasts from historical observations. |
| **Anomaly Detection** | Identify unusual patterns and deviations in climate data. |
| **Automated Alerts** | Surface conditions that require attention through an alert management interface. |
| **Role-Based Access** | Provide access to application features according to user roles. |
| **Processing Workflows** | Manage data processing tasks with Hadoop processing support. |
| **Administration** | Access dedicated tools for application administration. |

---

## Platform Workflow

1. **Sign in** to access the platform according to your assigned role.
2. **Import data** using the CSV or JSON ingestion interface.
3. **Process datasets** through the available processing workflows.
4. **Explore observations** using dashboards, station views, and the data explorer.
5. **Analyze patterns** with temperature forecasting and anomaly detection.
6. **Review alerts** to investigate conditions that need attention.
